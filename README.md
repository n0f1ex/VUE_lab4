### Styles.* (lab4-8)
Основная часть страницы может быть сделана, например, через .css to .scss online convertor (я так не делал);
Цикл в .scss сделан через @for $n from 1 through 100
Цикл в .sass также сделан через @for $n from 1 through 100
Если между .scss и .sass различий не так много, то в .less отсутствует понятие цикла for;
В .less используется рекурсивный вызов миксина с условием when 
.generate-colors(@n) when (@n > 0) {
    ...
    .generate-colors(@n - 1);
}
### Typescript (lab4-9)
Из интересных отличий TypeScript от JavaScript:
Возможность создавать интерфейсы и псевдонимы типов, а также перегружать функции, уменьшая объём кода
Так как Typescript компилируется в JavaScript, компилятор будет подсказывать ошибки в коде (лайк)
